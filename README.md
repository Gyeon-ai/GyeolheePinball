# 결희 종겜핀볼

SOOP 라이브 후원을 수집해 [결희 종겜핀볼 사이트](https://gyeon-ai.github.io/GyeolheePinball-Web/)에 사용할 목록을 만드는 Windows 프로그램입니다.

**바로 다운로드:** [자동판](https://github.com/Gyeon-ai/GyeolheePinball/raw/refs/heads/main/%EA%B2%B0%ED%9D%AC%20%EC%A2%85%EA%B2%9C%ED%95%80%EB%B3%BC%28%EC%9E%90%EB%8F%99%29.exe) · [일반판](https://github.com/Gyeon-ai/GyeolheePinball/raw/refs/heads/main/%EA%B2%B0%ED%9D%AC%20%EC%A2%85%EA%B2%9C%ED%95%80%EB%B3%BC.exe)

## 일반판과 자동판

| 판 | 차이 |
|---|---|
| 일반판 | 수집 목록을 복사하거나 저장하고 핀볼 사이트를 엽니다. |
| 자동판 | Chrome으로 핀볼 사이트를 열 때 수집 목록의 자동 입력을 시도합니다. |

## 주요 기능

- SOOP 라이브 채팅과 별풍선, 애드벌룬, 도전미션 후원을 수집합니다.
- 닉네임 모드에서는 조건에 맞는 후원을 즉시, 채팅 내용 모드에서는 후원자의 다음 채팅 1회를 수집합니다.
- 후원 종류와 `정확히 N개` 또는 `N개 이상` 조건을 선택할 수 있습니다.
- 수집 목록을 검색하고, 복사하고, 메모장 파일로 저장할 수 있습니다.
- 일반판과 자동판 모두 결희 핀볼 사이트를 엽니다.

## 이번 업데이트

### 1.0.0.6

- 자동판이 핀볼 사이트 준비를 기다린 뒤 수집 목록을 입력하도록 안정성을 개선했습니다.
- 입력한 내용과 사이트의 코인 수를 확인해 반영 실패를 잘못 성공으로 판단하지 않도록 했습니다.
- 일반판의 동작과 수집·코인 규칙은 그대로입니다.

### 1.0.0.5

- 패치 설명을 `업데이트 내용` 테두리 박스로 구분했습니다.
- 안내창의 작은 상단 제목을 없애고 닫기 버튼을 큰 제목 높이에 맞췄습니다.
- 안내창의 좌우·하단 여백을 줄였습니다. 본 프로그램의 글씨와 수집·코인 규칙은 그대로입니다.

### 1.0.0.4

- 일반판과 자동판에 새 버전 확인 및 **업데이트 / 나중에** 선택 기능을 추가했습니다.
- 업데이트 파일을 검증하고, 적용에 실패하면 기존 프로그램을 복구하도록 했습니다.
- 업데이트 안내창과 수집된 내용·코인·설정 영역의 가독성을 개선하고 내용 복사·메모장 저장 버튼의 글씨를 보강했습니다.
- 긴 닉네임을 위한 후원 정보 글씨 크기와 수동 테스트·모두 지우기 버튼은 유지했습니다. 기존 화면 문구와 수집·코인 규칙도 그대로입니다.

**1.0.0.2 이하 버전 사용자는 위 다운로드 링크에서 새 EXE를 한 번 직접 받아 실행해 주세요.** 1.0.0.4부터는 이후 새 버전이 나오면 프로그램에서 업데이트 여부를 선택할 수 있습니다.

### 1.0.0.2

- 창 너비나 높이가 작을 때 하단 버튼과 설정 영역이 잘리는 문제를 수정했습니다.
- 코인 합계가 커져도 숫자와 단위가 보이도록 표시 영역을 개선했습니다.
- 수집 목록에서 이름과 코인을 편집할 때 입력칸의 세로 정렬을 맞췄습니다.
- 기존 화면 문구와 글꼴, 수집 조건 및 코인 계산 규칙은 유지했습니다.

### 1.0.0.1

`정확히 N개` 조건은 N의 배수에도 적용됩니다. 예를 들어 N이 200개면 200개와 400개가 반영되고 300개는 반영되지 않습니다. 코인 계산은 기존 10회당 1코인 추가 규칙을 유지합니다.

자동판의 사이트 입력 기능은 Chrome 환경과 사이트 상태에 따라 동작하지 않을 수 있습니다. 그때는 프로그램의 내용 복사 기능을 사용해 직접 입력할 수 있습니다.
